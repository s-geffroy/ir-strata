# Spécification maître — Atlas V1

## Objet

Ce modèle estime, de 1815 à 2026, le poids relatif des grandes familles théoriques des relations internationales dans l’explication du système international.

Il distingue trois couches :

1. `strategic_reality` — ce qui structure réellement le système international.
2. `political_doctrine` — ce que les acteurs croient, revendiquent ou mobilisent.
3. `academic_influence` — le poids des écoles dans le champ intellectuel des RI.

La couche `synthesis` est générée à partir des trois couches précédentes.

## Décisions structurantes

- Scores bruts canoniques, scores normalisés générés.
- Taxonomie à deux étages : grandes familles + sous-familles activables.
- Tags transversaux : polarité, ordre, dynamiques, structures.
- Données globales pour toutes les périodes.
- Entités détaillées seulement pour périodes P1.
- Controverses structurées sur les points historiographiques sensibles.
- Statut de maturité par objet.
- Révision via Git + CHANGELOG + `revision_log` sélectif.
