# Taxonomie

## Grandes familles

1. Réalisme
2. Libéralisme
3. Marxisme / structuralisme / dépendance
4. Constructivisme
5. École anglaise
6. Critiques / postcoloniales / féministes
7. Géopolitique / impérialisme / raison d’État

## Règle anti-confusion

La géopolitique classique n’est pas absorbée automatiquement dans le réalisme. Le réalisme lit puissance, sécurité et anarchie ; la géopolitique lit territoire, routes, ressources, profondeur stratégique et empires.

## Sous-familles

Les sous-familles sont activées seulement lorsqu’elles améliorent réellement la période. Elles ne doivent pas être scorées partout.

## Tags transversaux

Les tags ne sont pas des théories autonomes. Ils qualifient une période, un événement, une preuve ou une entité.
